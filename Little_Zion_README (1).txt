LITTLE ZION HOMESCHOOL — PROTOTYPE
=========================================
Ages: 3–6
Devices: phones, tablets and laptops

Included in this prototype:
- Parent registration flow
- Child profile
- Subscription/locked-entry concept
- Demo payment unlock (NO REAL MONEY)
- Parent dashboard
- Child mode
- ABC & phonics activity
- Maths activity
- Pre-writing canvas
- Story time
- Memory game
- Stars/progress
- Responsive layout for phone/tablet/laptop
- Local progress storage

IMPORTANT:
This is a functional product prototype, not a production payment/authentication system.
Before selling access:
1. Connect a secure backend for accounts and sessions.
2. Use a real payment/subscription provider and verify subscription status server-side.
3. Add secure password reset and email verification.
4. Implement a parent gate for purchases/account controls.
5. Add a real database for child progress.
6. Create privacy policy, parental consent and child-data controls.
7. Complete Google Play/App Store compliance and review.
8. Replace placeholder curriculum/artwork/audio with original/licensed assets.
9. Have the curriculum reviewed by an early-childhood education professional.

The prototype uses R99/month as a placeholder price and a simulated payment button.
